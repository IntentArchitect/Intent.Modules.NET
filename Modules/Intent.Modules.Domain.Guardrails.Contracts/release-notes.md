### Version 1.0.0

- New Feature: Create authoritative design visuals for existing code in the Domain designer: entities, value objects, enums, repositories, data contracts, domain services and domain events.
- New Feature: Drift detection report when the Domain designer's visuals and the code go out of sync.
- New Feature: Use the `initialize-brown-field` or `reverse-engineer-domain` skill to set up your project, modelling the existing code and configuring the drift check from tested recipes for EF Core, MongoDB and Azure Cosmos DB.
